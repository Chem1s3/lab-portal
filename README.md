# Lab Portal

Публичная страница лаборатории. Записи хранятся в одной Google Таблице на отдельных листах, документы — в закрытой папке Google Диска.

## Подключить Google

1. Откройте https://script.google.com и нажмите «Новый проект».
2. Замените код в `Code.gs` содержимым `apps-script/Code.gs` из репозитория.
3. Вверху выберите функцию `setup`, нажмите «Выполнить» и подтвердите разрешения.
4. Откройте журнал выполнения: результат содержит `spreadsheetUrl` и `driveUrl`.
5. Нажмите «Развернуть» → «Новое развертывание» → тип «Веб-приложение».
6. Выполнять от вашего имени; доступ — «Все» для пилотного запуска.
7. Скопируйте адрес `/exec`, откройте сайт, нажмите «Подключить Google» и вставьте его.

Не публикуйте саму таблицу и папку. До загрузки реальных персональных данных необходимо добавить строгую авторизацию и серверную проверку ролей.
