Тест Google-входа Lab Portal

Это временная страница для первой регистрации владельца. Она не меняет основной сайт и не запрашивает пароль Google.

Открой страницу с адреса https://chem1s3.github.io/lab-portal/lab-portal-google-login-test.html. Не запускай HTML двойным щелчком с компьютера: Google проверяет разрешённый адрес сайта.

Скопируй Client ID из Google Cloud → Google Auth Platform → Clients → Lab Portal Web Client. Это публичный идентификатор; он не сохраняется на странице. Не вводи Client secret.
Ожидаю Client ID.

После входа будет отправлен запрос whoami на ваш тестовый Apps Script. Из-за ограничений CORS страница не может подтвердить ответ сервера. Для проверки открой Google Таблицу → лист users и найди строку с role = owner и заполненным googleSub. Не присылай никому Google ID-токены.
